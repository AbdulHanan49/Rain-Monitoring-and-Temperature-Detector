
# 🌧️ Rain Monitoring & 🌡️ Temperature Detector System  

## 📌 Introduction  
With climate change becoming a global concern, **real-time weather monitoring** has become crucial for **agriculture, urban planning, and disaster management**. This project combines **rainfall monitoring** and **temperature detection** to provide valuable weather insights.  

Our system utilizes **ESP-32, DHT-11, and YL-83 sensors** to measure **rainfall intensity** and **temperature variations**, process the data, and generate alerts based on predefined thresholds.  

## 🎯 Project Goals  
✅ **Real-time Rainfall Monitoring** – Accurately measure rainfall intensity and duration using sensors.  
✅ **Temperature Detection** – Monitor temperature variations in the targeted area.  
✅ **Data Analysis & Visualization** – Process and display collected data in an easy-to-understand format.  
✅ **Alert System** – Notify users of significant changes in weather conditions.  

## 🚀 Applications  
🔹 **Agriculture** – Helps farmers make informed decisions about irrigation, crop selection, and pest control.  
🔹 **Urban Planning** – Assists city planners in designing drainage systems and flood mitigation strategies.  
🔹 **Environmental Monitoring** – Supports researchers in studying climate trends and environmental changes.  
🔹 **Infrastructure Maintenance** – Aids in assessing weather impact on roads, bridges, and other structures.

## 🛠️ Hardware Requirements  
- 🖥️ **Main Board:** ESP-32  
- 🌡️ **Temperature Sensor:** DHT-11  
- ☔ **Rain Sensor:** YL-83  

## 📝 Setup & Installation  
1️⃣ Connect **ESP-32** with **DHT-11** and **YL-83** as per the circuit diagram.  
2️⃣ Flash the firmware onto **ESP-32** using **Arduino IDE or PlatformIO**.  
3️⃣ Monitor real-time weather data via **serial output or a web dashboard**.  
4️⃣ Implement an **alert system** for significant weather changes.
